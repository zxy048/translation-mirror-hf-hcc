# Translation-related transcriptional programs in HCC and heart failure

Public code and documentation for the harmonised cross-disease reanalysis of
translation-related transcriptional programs in hepatocellular carcinoma and
heart failure.

- [Analysis pipeline, environment and known limitations](Code/README.md)
- [Archive of the superseded first analysis](archive/README.md)
- [Manuscript source](Manuscript_PLOSONE_v2.md)

All data analysed here are public (GEO accessions and TCGA-LIHC); no new
primary data were generated.
